# Daymark — Everyday Toolkit

A small daily checklist prototype using HTML, CSS, JavaScript, and browser local storage.

Features: add tasks, mark complete, remove individual tasks, remove completed tasks, reset list, persist in this browser.

Run: open `index.html` in a modern browser.

Limitations: tasks stay in this browser and are not synced or encrypted. This is not a production productivity service.

Future improvements: due dates, priorities, categories, export/import, keyboard and screen-reader testing, automated tests.
